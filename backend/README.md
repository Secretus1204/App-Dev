Project Title:
Library Management System

Short Project Description:
The Library Management System is a web and mobile-based application designed to simplify the management of books, users, and borrowing transactions. It uses Laravel as the backend API, React for the web application, React Native for the mobile application, and MySQL for the database. The system uses Role-Based Access Control (RBAC) with two roles: Admin, who manages books, users, and borrowing requests, and User, who can search for books, request to borrow them, and view their borrowing history.
